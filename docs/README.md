## Regras de ouro

1. **Um documento vive em um só lugar** — links apontam, nunca copiam.
2. **"Promover o genérico, manter o específico"** — o que é transversal a mais de um produto sobe
   para a [`platform-standards`](https://github.com/fbso-techsolutions/platform-standards).
3. **Projeto entrega, produto define** — o que é entrega (PRD, B-REQ, backlog, sprints, enablers)
   vive no projeto; o que é definição (visão, branding, arquitetura) vive aqui.
